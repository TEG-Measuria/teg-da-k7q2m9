From VisiOffice to the order: importing measurements

7 minutes · Systems

Screen pictures coming soon. These steps come from our written guides. If your Optix One (desktop) screen looks different, follow your manager and tap Report a wrong step.

Purpose

After this lesson you can bring a VisiOffice session into an Opsysweb order using IMPORT MEASUREMENTS and check it arrived correctly. Importing saves retyping and removes keying errors.

Worked example

Mr Y, 59, caretaker, was measured in VisiOffice an hour ago. Now you start his XR Design order.

  1. In Opsysweb choose New order.
  2. Press IMPORT MEASUREMENTS. A list of VisiOffice sessions opens, by patient reference (surname, initial) and submitted date and time.
  3. Find Mr Y by surname and initial. If there are two sessions, choose the latest unless the list tells you otherwise.
  4. Select it. The order fills from the session.
  5. Check the special parameters: Eyecode is on, and the PDs, heights, cape and ERC values look right.
  6. Carry on with the rest of the order. Stop at SAVE.

The lesson

What the import does. IMPORT MEASUREMENTS opens the UMS list of VisiOffice sessions. Selecting one fills the order from it.

Steps.

  1. Start a New order in Opsysweb.
  2. Choose IMPORT MEASUREMENTS.
  3. Find the patient by reference (surname, initial) and the submitted date and time.
  4. Check you have the right person. A similar surname is a common error.
  5. Select the session.
  6. Look at the special parameters that arrived. For an XR Design these include eyecode, cape, ERC for each eye, PDs, heights, and box size. For XR Pro they also include panto, wrap, dominant eye and the NVB code.
  7. Compare the PDs and heights with what you measured at the dispense. They should agree.
  8. Continue with the order form and finish at SAVE.

If the session is not in the list. It may not have been submitted from the VisiOffice device. Check with the person who measured. If it cannot be found, use the fallback averages from the eyecode lesson and note why.

Check the Eyecode tick. The session should leave Eyecode on for eligible lenses.

Do not edit the measured values without a reason. If something looks wrong, ask the person who measured.

Do not press SEND. The order is sent only by a trained person.

These steps come from documents. Check with your practice manager: how the VisiOffice device submits sessions in your practice, and the Glass & Glass account flow.

Watch-outs

  • Choosing the wrong person from the list.
  • Not checking the imported PDs against the dispense.
  • Retyping measurements by hand when a session exists.
  • Using the wrong session when there are two.

Tips

  • Measure first, then order; the session is only useful if it is in the list.
  • Check the submitted time to pick the right session.
  • Keep the patient reference format consistent.

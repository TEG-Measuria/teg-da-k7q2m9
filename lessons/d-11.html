Quoting to the penny: building a full quote

9 minutes · Pricing

Purpose

After this lesson you can build a complete quote from the lists: frame, lens pair and extras, and read out one total. A quote that is right to the penny the first time builds trust and prevents awkward conversations at collection.

Worked example

Mrs T, 66, retired nurse, is a Gold member. She has chosen a frame and wants Comfort Max varifocals in the 1.6 index, clear, with no extras.

  1. Frame. Find the frame's price on the frame list. Mrs T is Gold, so you read the Gold column.
  2. Lenses. Find Comfort Max, Thin & light 1.6, clear, in the Gold columns: £316 for the pair. (Standard would be £395.)
  3. Extras. No extras, so nothing to add.
  4. Add: frame (Gold) + lenses (Gold) + extras = total.
  5. Say it in order: "The frame is X, the lenses for the pair are Y, so the total is Z."
  6. Check Optix One (desktop) shows the same total. If not, stop and ask.

The lesson

Build the quote in four steps, always in this order.

  1. Frame. Read the price from the frame list. Standard column for a non-member; Gold column for a Gold member.
  2. Lens pair. Read the cell: design, index band, clear or Transitions. Use the Gold figure for a Gold member. It is a price per pair.
  3. Extras. Add reglaze, tint and so on only if the patient wants them. For polarised, mirror and XTRActive, ask in practice and confirm before you quote.
  4. Total. Add the three. Say the three parts then the total.

Gold means Gold throughout. A Gold member's frame uses the Gold frame column and their lenses use the Gold lens columns. A non-member uses the standard columns throughout. Do not mix them. Never override a price.

Second pairs and codes. If a code applies (second pair, NHS voucher), work out the quote with the code in mind and say so clearly. See the code lessons.

Say it, then show it. Write the quote on the job sheet or show the screen so the patient can see the figures. Read it aloud once. Ask whether they would like to go ahead.

Offer a choice when it helps. If the patient may prefer a different lens, quote two options clearly side by side. Do not keep changing your answer.

Check the till. After you add the items in Optix One (desktop), the screen total must match the quote. If it does not, find out why before taking any payment. Never fix it by overriding a price.

Keep a copy. Note the quote on the job so anyone who picks it up sees what was agreed.

Watch-outs

  • Mixing a Gold frame with standard lens prices, or the reverse.
  • Forgetting extras and adding them at collection.
  • Quoting from memory.
  • Taking payment when the till total does not match the quote.

Tips

  • Write the quote in four lines: frame, lenses, extras, total.
  • Use Price-it to rehearse until each cell is quick to find.
  • If the patient asks "what if I go thinner?", re-read the next band rather than guessing.

Current practice notes

  • Gold members use the Gold frame and lens columns; others use the standard columns.
  • All lens prices are per pair.
  • Staff cannot override a price in the till.

Drill

Choose any frame price and any design on the lists. Write a four-line quote (frame, lenses, extras, total) for a non-member, then for a Gold member. Say both aloud.

Show model answer

for the non-member use the standard frame and standard lens cell; for the Gold member use the Gold frame and Gold lens cell. Extras are added only if wanted. Total = frame + lens pair + extras. Both quotes are read from the lists, none calculated by hand.

Today on the floor

Build a four-line quote (frame, lenses, extras, total) from the printed lists for a non-member, then a Gold member. Say both aloud to your coach.

About 5 minutes, with your coach.

What your coach looks for

  • Every figure read from the printed lists
  • Total adds up to the penny
  • Gold figure differs where the lists say so
